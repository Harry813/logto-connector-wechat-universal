# Contributing

Contributions are welcome for reproducible connector behavior, documentation, tests, and compatibility improvements.

## Before submitting a change

1. Do not include real credentials, production URLs, OAuth responses, or personal data.
2. Add or update a test for every behavior change.
3. Run `npm test` with Node.js 22.14 or a later Node.js 22 release.
4. Keep the UnionID-only identity rule unless a proposal demonstrates a safe cross-application identity model.
5. Explain the Logto and WeChat versions or account capabilities used for integration testing.
