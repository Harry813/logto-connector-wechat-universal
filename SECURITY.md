# Security Policy

## Supported versions

Only the latest tagged release is considered for security fixes. This project is experimental and does not provide a service-level guarantee.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** form under the repository Security tab. Do not open a public issue containing:

- WeChat AppIDs or AppSecrets;
- OAuth authorization codes or access tokens;
- Logto database records;
- `openid`, `unionid`, nicknames, avatar URLs, or other user data;
- production domains, callback URLs, or infrastructure details that are not already public.

Include the affected version, reproduction steps, impact, and a minimal redacted example. Maintainers will acknowledge a complete report when available, but no response-time guarantee is provided.
